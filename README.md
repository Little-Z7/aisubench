# AISUBench

AI 订阅服务评测基准（AI Subscription Benchmark）。

AISUBench 用于对各类 AI 订阅产品（ChatGPT Plus、Claude Pro、Gemini Advanced、Kimi、豆包 等）做系统性的评测与对比，帮助用户和开发者回答一个问题：

> 花同样的订阅费，哪个 AI 服务更值得？

## 评测维度（规划中）

- **模型能力**：代码、数学、推理、写作、多语言、多模态等标准化测试集表现
- **订阅权益**：额度 / 限速、上下文长度、高级功能（Deep Research、Agent、代码工具等）可用性
- **实际体验**：响应延迟、稳定性、限流策略、长任务完成率
- **性价比**：单位价格可获得的有效产出
